# Student Database

Projects completed for the freeCodeCamp Relational Database curriculum.

## Contents

- `part-1/` - Student database SQL dump
- `part-2/` - Student database SQL dump and query script

The two supplied SQL exports were identical, so the verified dump is included in both folders. Part 2 also includes `student_info.sh`, which runs the required PostgreSQL queries against the `students` database.

## Running Part 2

```bash
chmod +x part-2/student_info.sh
./part-2/student_info.sh
```
